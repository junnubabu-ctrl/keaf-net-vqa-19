# Dataset Setup

Create the following directory structure:

```text
data/
  coco/
    train2014/
    val2014/
  okvqa/
    annotations/
  aokvqa/
    annotations/
  gqa/
    annotations/
  conceptnet/
  cskg/
  features/
  vocab/
```

Do not redistribute benchmark images or annotations unless their licenses allow it. Provide download links and scripts only.

For reviewer evaluation, keep a `data_manifest.json` with file names, checksums, and download dates.
