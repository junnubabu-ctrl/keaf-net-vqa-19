## Remaining scientific defects and restrictions
Text NLI cannot establish external truth or image grounding. QA-pair serialization
as a hypothesis is only a proxy and must be compared with declarative hypotheses
and independently annotated multimodal support. Withholding both conflicting
items is a heuristic and can over-abstain. Provenance is retained but no source
trust probability is inferred from domain names. Pairwise support is O(k^2),
and duplicate source families do not establish independent corroboration.

The old `vqa_soft_accuracy` is a simplified score, not an official evaluator;
use the official OK-VQA / A-OKVQA scripts and record their exact commits.
The old AURC interpolates from a fictional zero-risk origin; do not use it for
scientific claims. The new risk curve has undefined risk at zero coverage and
uses only achievable tied-score thresholds. Declare an AURC convention before
analysis; hard-gated policies cannot achieve full coverage, so report the curve's
maximum attainable coverage and also the ungated ranking curve separately.

No source calibration, threshold calibration, evidence annotations, licensed
benchmark snapshots, baseline reproduction, or GPU experiments were performed.
The run script emits raw candidates and explicitly unfitted support scores.
